# Enunciado original — Shape Drawable con líneas en ImageView

Ejercicio histórico del bloque **Shapes Drawables** en Android.

Crear dos `ImageView` y asignarles mediante recursos XML un `shape drawable` que represente líneas horizontales verdes. El objetivo es practicar la definición de formas y trazos en recursos XML y su reutilización desde la interfaz, sin sustituirlos por dibujo imperativo en código Java.

La versión actual mantiene el uso de drawables XML porque constituye precisamente el contenido del ejercicio.

No existe una base de datos asociada.
